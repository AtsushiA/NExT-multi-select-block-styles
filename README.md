# Multi Select Block Styles

WordPressのブロックエディタでスタイルの複数選択を可能にするプラグインです。

## 機能

- ブロックエディタの「Styles」パネルで複数のスタイルを同時に選択可能
- 選択したスタイルは `is-style-*` クラスとしてブロックに追加されます

## インストール

1. このリポジトリをダウンロードまたはクローン
2. `wp-content/plugins/` ディレクトリに配置
3. WordPress管理画面でプラグインを有効化

## 使い方

1. 投稿または固定ページの編集画面を開く
2. ブロック（例：見出し、段落など）を選択
3. 右サイドバーの「Styles」パネルで複数のスタイルをクリック
4. クリックするたびにスタイルの追加/削除がトグルされます

## 要件

- WordPress 5.0以上
- ブロックエディタ（Gutenberg）
